## Overview
AutoCAD for Windows is Autodesk's professional computer-aided design application, used across engineering, architecture, and manufacturing to produce accurate 2D drawings and 3D models. It gives design professionals a precise drafting environment with layers, blocks, and dimensioning tools built for technical documentation, plus 3D modeling for visualizing a design before it gets built.

## Features
| Feature | What it does for you |
|---|---|
| Precision 2D drafting | Create accurate technical drawings with exact measurements |
| 3D modeling | Build and visualize 3D models of parts, products, and structures |
| Extensive block libraries | Reuse standard symbols and components across drawings |
| Layer and layout management | Organize complex drawings into clear, manageable views |
| DWG file compatibility | Work in the industry-standard .dwg format used across the design industry |

> **Tip:** Keep dimensions, annotations, and geometry on separate layers so complex drawings stay easy to manage as they grow.
